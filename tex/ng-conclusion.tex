На этой выборке кластеры Nomic лучше всего восстановили рубрики. При штатном пороге повторный выбор темы по описаниям Qwen снизил тестовую AMI с 0,548 до 0,374. Подбор порога по отдельным 200 письмам сохранил исходную кластеризацию. Названия позволяют объяснить содержание кластеров, однако описание пяти ближайших писем может оказаться слишком узким для остальных документов.
